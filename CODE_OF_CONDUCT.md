# Code of conduct

`code-oz` adopts the **Contributor Covenant, version 2.1** as its code of conduct.

The full text is published at:

- HTML: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Markdown source: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md>

Adopting the Covenant by reference (rather than inlining the text) keeps this file synchronized with the upstream version and avoids drift if Contributor Covenant publishes a newer revision.

## Scope

The code of conduct applies to all project spaces:

- This GitHub repository (issues, pull requests, discussions, commit messages, code comments).
- Any official communication channel maintained by the project.
- Any public space when an individual is representing the project.

## Reporting

To report behavior that violates the code of conduct, email **conduct@tuel.ai**.

Reports stay confidential. The maintainers will acknowledge within 3 business days and respond per the enforcement guidelines published in the Contributor Covenant 2.1 text linked above.

For security-sensitive reports (vulnerabilities, exposed credentials, supply-chain concerns), see [`SECURITY.md`](SECURITY.md) instead — that path is private and time-bounded.
