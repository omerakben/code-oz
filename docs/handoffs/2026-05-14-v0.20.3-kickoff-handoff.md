#### A2. npm publish `@tuel/code-oz@0.20.2-alpha.0` (~15 min)

Steps that have to happen in order:

1. **Bump `npm-wrapper/package.json` version** if it isn't already at `0.20.2-alpha.0`. Check first; the root package.json bump (commit `fb73128`) may not have propagated to the wrapper.
2. **`npm pack` dry-run** from `npm-wrapper/` — verifies the tarball composition without publishing.
3. **`npm config get @tuel:registry`** — must be `https://registry.npmjs.org/` or the literal string `undefined`. If overridden, pass `--registry=https://registry.npmjs.org/` per the trap doc in TRUST.md.
4. **`npm publish --access public`** from `npm-wrapper/`. The wrapper has NO postinstall hook — the binary downloads + SHA-verifies on first run, not at install (see TRUST.md § "Install trust" for the contract).
5. **Smoke** in a fresh terminal: `npm install -g @tuel/code-oz@0.20.2-alpha.0 --registry=https://registry.npmjs.org/` then `code-oz --version` → must report `0.20.2-alpha.0`. The first-run will download the per-arch binary from the v0.20.2 GitHub release and cache it at `~/.cache/code-oz/0.20.2-alpha.0/code-oz`.

### Workstream C — How to work Claude + Codex together (proven pattern from v0.20.2)

Last session's discipline worked. Worth keeping verbatim for this one:

1. **For non-trivial code changes, dispatch a Codex debate brief FIRST** (read-only sandbox, gpt-5.5 xhigh). Capture as `docs/design/V0_20_3_<FINDING>_BRIEFING.md` + `..._CODEX_RESPONSE.md`. Locked decisions land in the brief's response synthesis. (Pattern: thread `019e281e` for #0a, thread `019e2827` for #0b.)
2. **For implementation review**, dispatch Codex on the staged diff after the failing-test-then-fix cycle. Read-only sandbox; the verdict is `push` / `fix-first` / `debate-required`. Close all block-push findings before merge; fix-soon can defer to a follow-up commit on the same branch.
3. **Expect 2-3 review rounds to converge** on non-trivial code. The pattern `feedback_codex_review_round_convergence.md` documents this: R1 catches load-bearing structural; R2 catches contract/doc drift; R3 confirms closure.
4. **Per-commit Codex review when touching shared infra** (locks, seams, contracts) per `feedback_per_commit_cross_model_review.md`. Worktree-reset (#1) is in this class — Codex should see the design BEFORE implementation.
