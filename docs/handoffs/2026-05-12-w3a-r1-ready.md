## Memory candidates from this session (consider saving)

- **`feedback_split_commit_for_consumer_first_test`**: When the
  consumer's RED-first test depends on an artifact contract that
  hasn't landed yet, split the consumer commit from the producer
  commit — even if the synthesis treats them as one unit. Cost: +1
  commit; benefit: each test fails for the right reason on RED.
- **`feedback_file_url_test_seam`**: For testing network-mode CLI
  code, using `file://` URLs against a controlled local release store
  exercises real curl/wget/tar end-to-end. No fake HTTP client
  needed; the test seam is the BASE_URL env var. Generalizes to any
  tool that downloads + verifies + extracts.
- **`feedback_eliminate_version_literal_via_indirection`**: When a
  bumpable constant could be read from a single source (e.g.,
  package.json:version), do that instead of hardcoding. One less
  tag-time straggler per literal eliminated. Cost: tiny runtime read;
  benefit: a class of release-residue bugs goes away.
